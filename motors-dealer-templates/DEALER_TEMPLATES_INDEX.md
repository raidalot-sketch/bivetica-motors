# 10 Dealer Website Templates — motors.bivetica.com

Complete template library for dealers to choose, customize, and deploy their own website.

---

## Template Directory

### **Template 1: Modern Grid** (Inventory-First)
**Best for:** Volume dealers, CarTake-style, search-heavy audience
- **Layout:** Search bar hero → large inventory grid
- **Style:** Minimal, clean, mobile-optimized
- **Color:** Blue/neutral
- **Focus:** Fast filtering, seeing many cars quickly
- **File:** `template-1-modern-grid.html`

### **Template 2: Luxury Showcase** (Featured-First)
**Best for:** High-end specialists, prestige brands
- **Layout:** Hero → 1 featured car (large) → full inventory below
- **Style:** Premium, white space, subtle
- **Color:** Gold/platinum accents
- **Focus:** Story + curation
- **File:** `template-2-luxury-showcase.html`

### **Template 3: Classic Auction** (Timeline/Lot Format)
**Best for:** Auction houses, collectors, numbered lots
- **Layout:** Lot number display → featured auction items → bidding info
- **Style:** Traditional, catalog-like, structured
- **Color:** Burgundy/cream
- **Focus:** Lot info, auction dates, reserve prices
- **File:** `template-3-classic-auction.html`

### **Template 4: Performance Sports** (Specs-Focused)
**Best for:** Sports car dealers, performance specialists
- **Layout:** Hero → performance specs prominently → vehicle comparison
- **Style:** High-energy, dark, technical
- **Color:** Red/black
- **Focus:** Horsepower, 0-60, track capability
- **File:** `template-4-performance-sports.html`

### **Template 5: Family Business** (Heritage/Personal)
**Best for:** Independent dealers, family-owned, personal touch
- **Layout:** Welcome message → dealer story → featured cars → team intro
- **Style:** Warm, personal, community-focused
- **Color:** Earth tones, custom palette
- **Focus:** Relationships, trust, longevity
- **File:** `template-5-family-business.html`

### **Template 6: Volume Dealer** (Maximum Inventory)
**Best for:** High-volume dealers, many makes/models
- **Layout:** Powerful search → advanced filters → infinite scroll grid
- **Style:** Functional, tool-like, data-dense
- **Color:** Blue/grey professional
- **Focus:** Finding specific car, 500+ inventory browse
- **File:** `template-6-volume-dealer.html`

### **Template 7: Dealer Network** (Multi-Location)
**Best for:** Franchise/multi-location dealers
- **Layout:** Location picker → location-specific inventory → central search
- **Style:** Corporate, organized, professional
- **Color:** Brand primary color (customizable)
- **Focus:** "Find local inventory", location services
- **File:** `template-7-dealer-network.html`

### **Template 8: Broker/Concierge** (White-Glove Service)
**Best for:** Broker dealers, bespoke services, high-touch
- **Layout:** Call-to-action (contact us) → featured acquisitions → services
- **Style:** Minimalist luxury, appointment-focused
- **Color:** Black/white/gold
- **Focus:** Personal service, bespoke sourcing, consultation
- **File:** `template-8-broker-concierge.html`

### **Template 9: Lifestyle Premium** (Aspirational/Luxury)
**Best for:** Dream-car dealers, lifestyle brands
- **Layout:** Immersive hero → lifestyle imagery → featured vehicles → community
- **Style:** Modern luxury, dynamic, lifestyle-oriented
- **Color:** Deep jewel tones, custom brand color
- **Focus:** Lifestyle, ownership experience, community
- **File:** `template-9-lifestyle-premium.html`

### **Template 10: Specialist Niche** (Focused Collection)
**Best for:** Specialist dealers (classic British, electric, restoration, etc.)
- **Layout:** Collection story → filter by subcategory → detailed specs
- **Style:** Curated, expert, detailed
- **Color:** Category-specific (e.g., green for electric)
- **Focus:** Expertise, specialization, deep specs
- **File:** `template-10-specialist-niche.html`

## Data Requirements Per Template

All templates need:
- Dealership profile (name, contact, address, hours, logo)
- Vehicle inventory (make, model, year, price, color, mileage, engine, transmission)
- Featured vehicles (select 3-6 from inventory)
- Custom brand colors (primary, secondary, accent)

Optional per template:
- Dealer story/about text (#5, #8, #9)
- Services list (#5, #7, #8, #10)
- Locations/branches (#7)
- Category/specialization info (#10)

## Support & FAQs

**Q: Can I switch templates later?**  
A: Yes, your inventory data transfers. New template renders with same vehicles.

**Q: Can I customize colors beyond primary/secondary?**  
A: Templates 1-8 have 2-3 color options. Custom CSS available as upgrade.

**Q: Mobile support?**  
A: All templates are mobile-first. Tested on iPhone, Android, tablets.

**Q: Can I add custom pages (About, Services)?**  
A: Basic pages included. Custom pages available as premium add-on.

**Q: What if I have 1000+ vehicles?**  
A: Use Template #1 or #6. Inventory grid uses pagination/infinite scroll.

**Q: Can multiple dealers use same template?**  
A: Yes. Each gets their own subdomain with their customized version.
